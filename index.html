🔗 Connexió Google Sheets

Enganxa aquí la URL del teu Apps Script per sincronitzar les dades al núvol.

📋 Com configurar-ho (passos ràpids):

  1. Obre Google Sheets i crea un full nou
  2. Ves a Extensions → Apps Script
  3. Esborra tot el codi i enganxa el codi que trobaràs a l'arxiu apps-script.gs
  4. Fes clic a Desplegar → Nou desplegament
  5. Tipus: Aplicació web · Accés: Qualsevol persona
  6. Copia la URL generada i enganxa-la aquí
